CSV format

Upload a UTF-8 CSV file. The first row must be a header. Column names are case-sensitive.

Point matching

Each row is matched to an existing point by point_label. If a point with that exact label already exists, the measurement is linked to it. If no match is found, a new point is created automatically.

Warning: label matching is case-sensitive. When adding measurements to an existing point, make sure the label is spelled exactly as it appears in the database (e.g. Point01 and point01 are treated as different points).

Required columns

  • point_label — point identifier (string). Must match an existing point exactly, or a new point will be created.
  • east — easting coordinate (float, EPSG:32632)
  • north — northing coordinate (float, EPSG:32632)
  • h — ellipsoidal height in metres (float)

Survey identification — provide exactly one

  • survey_id — integer primary key of an existing survey (use this when multiple surveys share the same date)
  • survey_date — survey date in DD/MM/YYYY format; fails if the date matches more than one survey

Optional columns

  • meas_date — measurement date (YYYY-MM-DD)
  • meas_strategy — strategy string (max 25 chars)
  • notes — free text (max 250 chars)
  • std_east, std_north, std_h — coordinate standard deviations in metres (float). Older templates using ds_east/ds_north/ds_h are still accepted.
  • lat, lon, h_orto — normally computed by the DB trigger on save; supply only to override

Example — survey by date

point_label,survey_date,east,north,h
Point01,25/07/2023,415946.624,5089448.188,2172.849
Point02,25/07/2023,415952.969,5089052.831,2173.273

point_label,survey_id,east,north,h
